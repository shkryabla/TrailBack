# TrailBack (ТропаДомой — «Возвращатель грибника»)

Офлайн-навигатор для грибников, охотников и туристов: запись трека, возврат
в начальную точку, компас и отмеченные места — без обязательного интернета.

## Основные функции

- Запись маршрута с отображением на офлайн-карте (Mapsforge)
- Режим "Домой" — возврат к точке старта по прямой (стрелка + линия на карте и компасе)
- Полноэкранный компас (истинный/магнитный север) и мини-компас на карте
- Отмеченные места с произвольным названием — координаты можно скопировать
  или открыть в стороннем навигационном приложении
- Восстановление трека при краше приложения (окно 72 часа)
- Локализация: русский и английский

## Работа без офлайн-карты

Офлайн-карта — вспомогательный, необязательный инструмент. Всё ядро навигации работает и без неё:

- точка входа фиксируется по GPS независимо от наличия карты;
- пройденный путь записывается и визуально отображается треком на экране — просто без картографической подложки под ним;
- режим «Домой» так же точно рассчитывает азимут и ведёт обратно к точке старта — расчёт идёт по координатам GPS, а не по данным карты.

Карта нужна только для визуальной привязки к местности — увидеть рядом с собой тропы, ручьи, реки, грунтовые дороги — то есть ориентиры, которых не видно на голом экране с треком и стрелкой. Само возвращение к точке старта от неё не зависит.

## Технологии

- Kotlin, MVVM, Room, Coroutines, ViewModel/LiveData
- Mapsforge (офлайн-рендеринг карт), Play Services Location (геопозиция)
- Min SDK 24, target SDK 34

## Сборка

Требования: JDK 17, Android SDK, Gradle 8.0+.

```bash
./gradlew assembleDebug
```

### Тесты

Юнит-тесты покрывают критичную логику: защиту от ложных GPS-срабатываний
диалога "Вы вернулись!" и окно восстановления трека после краша (72 часа).

```bash
./gradlew test
```

### Релизная сборка с подписью

1. Скопируйте `keystore.properties.example` в `keystore.properties` и заполните
   реальными данными (этот файл не должен попадать в репозиторий).
2. Выполните:

```bash
./gradlew bundleRelease
```

### CI/CD

- `.github/workflows/release.yml` — сборка и подпись AAB/APK при пуше в `main`
  или создании тега `v*`; секреты: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`,
  `KEY_ALIAS`, `KEY_PASSWORD`.
- `.github/workflows/debug.yml` — несигнированная debug-сборка для веток и PR.
