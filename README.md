# TrailBack (ТропаДомой — «Возвращатель грибника»)

Полностью офлайн-навигатор для грибников, охотников и туристов: запись
трека, возврат в начальную точку, компас и отмеченные места — без интернета
вообще, ни в каком виде.

## Основные функции

- Запись маршрута с отображением на офлайн-карте (Mapsforge) — сглаженная
  линия, архивные треки хранятся постоянно вместе с точками входа
- Режим "Домой" — возврат к точке старта по прямой (стрелка + линия на карте и компасе)
- "Взятие направления" — долгий тап по карте задаёт произвольную точку-цель,
  независимо от режима записи маршрута и от "Домой"
- Полноэкранный компас (истинный/магнитный север) и мини-компас на карте —
  курс и сторона света вынесены отдельной строкой над диском, засечки и
  цифры шкалы читаются по контуру кольца
- Отмеченные места с произвольным названием — список с контекстным меню
  на каждую запись (открыть в навигаторе / скопировать координаты /
  показать на карте / удалить), плюс ручное добавление места по кнопке "+"
  с вводом координат текстом
- Автоматический JSON-бэкап точек входа, отмеченных мест и треков в выбранную
  SAF-папку — переживает удаление приложения; при повторной установке и
  выборе той же папки данные тихо восстанавливаются, а не затираются
- Восстановление трека при краше приложения (окно 72 часа)
- Локализация: русский и английский

## Работа без офлайн-карты

Приложение принципиально офлайн — онлайн-провайдера карт в коде больше нет
вообще (вырезан полностью, никакого сетевого фолбэка). Варианта экрана карты
всего два: загруженная офлайн-карта Mapsforge, либо рабочая заглушка.

Офлайн-карта — вспомогательный, необязательный инструмент. Всё ядро навигации работает и без неё:

- точка входа фиксируется по GPS независимо от наличия карты;
- пройденный путь записывается и визуально отображается треком на экране — просто без картографической подложки под ним;
- режим «Домой» так же точно рассчитывает азимут и ведёт обратно к точке старта — расчёт идёт по координатам GPS, а не по данным карты;
- зум и курсор текущего положения работают и на заглушке — это не статичная картинка, а полноценный рабочий слой карты без тайлов.

На заглушке вместо тайлов — адаптивная масштабная сетка (шаг по
картографическому ряду 1-2-5 м/км, подстраивается под текущий зум) с
подписью шага в углу, для ощущения расстояния без самой карты.

Долгий тап (сохранить место / взять направление) доступен **только** когда
реально показаны офлайн-тайлы — на заглушке заблокирован: без видимых
ориентиров на местности (троп, ручьёв, дорог) осмысленно выбрать точку
нельзя.

Карта нужна только для визуальной привязки к местности — увидеть рядом с собой тропы, ручьи, реки, грунтовые дороги — то есть ориентиры, которых не видно на голом экране с треком и стрелкой. Само возвращение к точке старта от неё не зависит.

## Технологии

- Kotlin, MVVM, Room, Coroutines, ViewModel/LiveData
- Mapsforge (офлайн-рендеринг карт), Play Services Location (геопозиция)
- Min SDK 24, target SDK 34

## Сборка

Требования: JDK 17, Android SDK, Gradle 8.0+.

```bash
./gradlew assembleDebug
```

### Тесты

Юнит-тесты покрывают критичную логику: защиту от ложных GPS-срабатываний
диалога "Вы вернулись!" и окно восстановления трека после краша (72 часа).

```bash
./gradlew test
```

### Релизная сборка с подписью

1. Скопируйте `keystore.properties.example` в `keystore.properties` и заполните
   реальными данными (этот файл не должен попадать в репозиторий).
2. Выполните:

```bash
./gradlew bundleRelease
```

### CI/CD

- `.github/workflows/release.yml` — сборка и подпись AAB/APK при пуше в `main`
  или создании тега `v*`; секреты: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`,
  `KEY_ALIAS`, `KEY_PASSWORD`.
- `.github/workflows/debug.yml` — несигнированная debug-сборка для веток и PR.
